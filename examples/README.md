# Examples

This directory is for synthetic fixtures only.

Allowed here:

- contract-shaped manifests
- synthetic audit events
- synthetic protected-intake records
- synthetic de-identification reviews
- synthetic intake gate reports
- synthetic analysis workspace records
- synthetic analysis units
- synthetic codebook versions, code applications, and memo records
- synthetic framework matrices and mixed-method joins
- synthetic team coding rounds and adjudication decisions
- synthetic assistive algorithm policy gates
- synthetic synthesis export records
- placeholder exports that demonstrate file format expectations

Not allowed here:

- raw study data
- identifiable transcripts or notes
- consent documents
- code keys
